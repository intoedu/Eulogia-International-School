# 07. 디자인 기준

## 1. 색

기준: 로고 남색. 로고 원본 이미지에서 측정한 값은 RGB(40, 46, 142)입니다.
로고 원본(벡터)을 받으면 정확한 값으로 다시 맞춥니다.

| 역할 | 색 | 쓰는 곳 |
|---|---|---|
| 기본 (로고 남색) | `#282E8E` | 제목, 메뉴, 주요 버튼 |
| 진한 남색 | `#1B1F66` | 하단 배경, 버튼 누름 상태 |
| 연한 남색 배경 | `#EEF0FA` | 구역 배경, 카드 |
| 강조 (따뜻한 노랑) | `#F2B632` | 큰 상담 버튼, 일정 강조. **한 화면에 1~2곳만** |
| 본문 글자 | `#1F2330` | 본문 |
| 보조 글자 | `#5A6072` | 설명, 날짜 |
| 선 | `#DDE0EA` | 구분선, 입력칸 테두리 |
| 배경 | `#FFFFFF` | 기본 배경 |

일정 구분색 (기존 학사 일정 이미지의 색 체계를 이어 씀)

| 구분 | 색 |
|---|---|
| 1학기 | `#A9C4F5` (연파랑) |
| 2학기 | `#C9EBA8` (연두) |
| 3학기 | `#F7EE7A` (노랑) |
| 4학기 | `#9CD39A` (초록) |
| 방학 | `#F5B5E6` (분홍) |

- 기존 사이트의 진녹색, 민트, 주황, 빨강 버튼은 쓰지 않습니다.
- 명도 대비 계산값 (웹 접근성 기준 AA는 본문 4.5 이상)
  - 흰 배경 위 남색 `#282E8E`: 11.2
  - 흰 배경 위 보조 글자 `#5A6072`: 6.3
  - 노랑 `#F2B632` 위 진한 남색 `#1B1F66`: 8.0
  - 노랑 위 흰 글자: **1.8로 기준 미달** → 노랑 버튼에는 반드시 진한 남색 글자를 씁니다

## 2. 글꼴

| 언어 | 글꼴 | 라이선스 |
|---|---|---|
| 한국어 | Pretendard | SIL OFL (무료, 상업 사용 가능) |
| 영어 | Pretendard (같은 글꼴로 통일) | 같음 |
| 태국어 (추가할 경우) | Noto Sans Thai | SIL OFL |

- 본문 16px 이상 (모바일 기준), 줄 간격 1.6
- 한·영 함께 표기에서는 한국어를 위에, 영어를 아래에 한 단계 작고 연하게 씁니다
  - 예: **입학 안내** / <small>Admissions</small>

## 3. 사진 원칙

- 실제 학교 사진만 씁니다. 무료 사진 사이트의 외국 아이 사진은 쓰지 않습니다 (기존 첫 화면 연필 사진 대체)
- 첫 화면 사진: 개인 학습석에서 공부하는 장면, 또는 유아반 야외 활동
- 아이 얼굴이 정면으로 나온 사진은 보호자 동의를 확인한 것만 씁니다
- 모든 사진에 설명(alt)을 붙입니다 (기존 사이트 약점 보완)

## 4. 문구 원칙

- 첫 문장에 「누구를 위한, 어떤 학교인지」를 씁니다 (나이, 지역, 강점)
- 근거 없는 최상급 표현을 피합니다 (예: 「the best choice」「most widely accepted」). 대신 숫자로 씁니다 (2013년 개교, 반당 10명, 2015년부터 Quality Status)
- 학교 이름 표기는 질문지 A1의 답으로 하나만 씁니다
- 학교의 신앙 관련 표현은 의뢰처가 정한 수준을 따릅니다 (질문지 F3)

## 5. 화면 원칙

- 모바일 우선으로 설계합니다. 주 방문자인 학부모·여행객은 휴대폰으로 볼 가능성이 높습니다 [추정]
- 모바일 하단 고정 바: [상담 신청] [전화] [카카오톡]
- 첫 화면을 가리는 팝업은 쓰지 않습니다 (경쟁 학교 3곳의 약점)
- PC에서는 주요 메뉴를 항상 펼쳐 보여 줍니다

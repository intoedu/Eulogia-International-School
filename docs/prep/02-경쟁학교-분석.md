## 3. 가져올 장점

1. **CMIS 수업료 표:** 학년별 금액과 부대비용을 한 페이지에 공개
2. **CMIS 방문 예약:** 신청서 칸(이름, 전화, 이메일, 자녀 생년월일, 입학 희망 연도, 희망 일시)과 신청 후 3단계 안내(연락 → 방문 → 후속 상담)
3. **Grace 학사 일정:** 표 형식, 연도별 다운로드
4. **NIS 언어별 투어와 LINE:** 외국인 학부모를 언어별로 챙김 → 율로기아는 한국어로
5. **NIS 입학 절차:** 「신청 후 5~7 영업일 안에 연락」처럼 기간을 명시, 준비 서류 목록 공개, 입학 담당자 인사말
6. **CDSC:** 언어 전환, 학부모 포털

## 4. 피할 약점

- 첫 화면 팝업 (CMIS, NIS, CDSC) → 율로기아는 공지를 첫 화면 안의 띠나 카드로 표시
- 메뉴 숨김 (NIS) → PC에서는 주요 메뉴를 항상 보이게
- 금액 없는 수업료 페이지 (Grace) → 공개하기로 하면 금액까지 표시

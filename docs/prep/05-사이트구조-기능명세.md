## 0. 「한·영 함께 표기」 방식 정리 [확인 필요]

신청한 기능은 **함께 표기**입니다. 한 화면에 한국어와 영어를 같이 보여 주는 방식이고, **언어 전환 버튼으로 페이지 전체가 바뀌는 방식이 아닙니다**.

- 적용안: 제목은 「입학 안내 Admissions」처럼 두 언어를 같이 쓰고, 본문은 한국어 단락 아래에 영어 단락을 둡니다.
- 위험: 본문이 길어지면 두 배로 길어집니다. → 본문은 요약형으로 쓰고, 긴 설명(ACE 교육 원리, LCA 졸업 요건)은 접었다 펴는 형태로 둡니다.
- 태국어를 추가하면 세 언어를 함께 표기하기 어렵습니다. → 그때는 언어 전환 방식으로 바꾸는 것을 별도 견적으로 제안합니다.

## 2. 페이지별 구성

### 홈

1. **첫 화면**
   - 학교명
   - 한 줄 소개 (예: 「치앙마이의 2~18세 영어 개별 진도 학교 · An individualized English-medium school for ages 2–18 in Chiang Mai」. 문구는 의뢰처 확인 필요)
   - 큰 버튼 「입학 상담 신청」 + 보조 버튼 「전화」「카카오톡」
2. **신뢰 숫자:** 2013년 개교 · ACE Quality Status (2015~) · 유아반 반당 10명 · LCA 졸업장 과정
3. **4개 과정 카드 (나이별):** 2~6세 / 초·중 / 고 / GED
4. **개별 진도 학습 설명:** 3단계 그림 (진단 평가 → 개인 진도 → 숙달 확인)
5. **다가오는 일정 3개:** 「일정」 목록에서 자동으로 표시
6. **최근 공지 3개 + 갤러리 6장**
7. **학부모 후기:** 자료를 받으면 추가
8. **오시는 길 요약 + 상담 버튼**
9. **하단:** 주소, 언어별 전화, 이메일, SNS, 개인정보 처리방침, 운영 법인명·학교 인가 번호 (ชม 01-001/2558). 대표 개인 신분증 번호는 표시하지 않음

공지는 **팝업으로 띄우지 않고** 첫 화면 위쪽 띠로 보여 줍니다 (경쟁 학교 분석 반영).

### 교육과정 (4개 상세 페이지 공통 틀)

대상 나이 → 하루 일과 또는 과목 → 특징 3가지 → 수업료(공개 시) → 사진 → 「이 과정 상담 신청」 버튼(신청서의 희망 과정이 자동 선택됨)

- **유아반:** LOVE반(K2-K3), HOPE반(K1) 시간표를 이미지가 아닌 표로 표시. 영어·태국어 수업과 Korean Class 포함
- **ACE:** 핵심 과목(수학, 영어, 어휘, 과학, 사회) 단계표, 선택 과목
- **이중 학적:** 졸업 요건 4종(Honors 28학점 / College Prep 26.5 / General 24 / Vocational 22), LCA 인증서 PDF, 대학 진학 목록 링크
- **GED:** 9학년 이후 준비 과정, ged.com 링크

### 입학 안내

1. 대상
   - 신입생: 6세 이상
   - 편입생: ACE 경험자, 미경험자는 진단 평가
   - 유아반: 2~6세
2. 절차 4단계: 상담 신청 → 학교 방문·진단 평가 → 서류 제출 → 등록·수업료 결제
3. 준비 서류: 의뢰처 확인 필요
4. 수업료 표: 공개 여부 확인 필요
5. 「신청 후 ○ 영업일 안에 연락드립니다」 안내

### 학사 일정 (목록·검색)

- 데이터: `data/school-calendar-2026-2027.csv`
- 보기 방식: 월별 목록이 기본이고, 다가오는 일정이 맨 위에 옵니다
- 구분 필터: 학기 / 방학 / 행사 / 교사 일정
- 검색: 일정 이름으로 검색
- 연도 선택: 2026-2027 (다음 학년도 추가 가능)
- 관리자가 일정 추가·수정 가능

## 5. 회원가입

- 가입 칸: 이름, 이메일, 비밀번호, 연락처, 자녀 학년(선택), 개인정보 동의
- 승인 방식: 자동 또는 관리자 승인 (확인 필요). 재학생 학부모 전용이면 관리자 승인을 권장
- 마이페이지: 내 Q&A, 결제 내역

## 6. 수강료 납부 안내 (QR·계좌이체) — 2026-10-28 결정: 카드 결제 제외

- 결제 페이지(/pay): 학교 PromptPay QR 이미지 + 은행·계좌 정보 + 송금 메모 안내(「학생 이름 + 과정」)
- 입금 확인증(슬립) 제출: 신청서 기능으로 접수 (학생 이름, 과정, 금액, 송금일, 슬립 사진)
- 관리자는 **슬립이 아니라 통장 실제 입금으로 확인** (가짜 슬립 대비)
- 선택 확장: 금액이 들어간 QR 자동 생성 (PromptPay 표준, 수수료 0원) — 가격표에 없는 항목이라 별도 협의
- 카드 결제는 나중에 원하면 추가 (가격표 기준 제작비 300,000원 · 월 50,000원)

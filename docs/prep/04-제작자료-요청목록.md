# 04. 제작 자료 요청 목록 (계약 후)

신청서 기준: 제작 자료는 계약서 서명 후 「제작 자료 링크」로 받습니다.
아래는 그 링크로 받을 항목입니다. 기존 제작 자료 양식에 없는 항목은 ★로 표시했습니다. 양식에 추가하거나 따로 요청하시면 됩니다.

## 1. 꼭 필요한 자료 (없으면 제작이 멈춤)

| 자료 | 형식 | 비고 |
|---|---|---|
| 로고 원본 | AI, SVG, PDF 또는 2000px 이상 PNG(배경 투명) | 지금 사이트에는 768px JPG만 있음 |
| 학교 공식 이름 (영·한·태) | 글 | 제작 자료로 받음. 기존 사이트에 5가지 이름이 섞여 있으니 하나로 받기 |
| 연락처 (언어별 전화, 이메일, 상담 시간) | 글 | 제작 자료로 받음 |
| 과정별 소개 확인 | 글 | 06 문서의 기존 내용을 그대로 쓸지, 고칠지 |
| 수업료 (공개 여부 포함) | 표 | 제작 자료로 받음 |
| 카드 결제 정보 (PG 가입 정보, 정산 통화) | 글 | 확인 질문지 1 (계약 전) |
| 도메인 관리 권한 | 계정 정보 또는 관리 업체 연락처 | 확인 질문지 2 (계약 전) |

## 2. 품질을 크게 높이는 자료

| 자료 | 형식 | 권장 수량 | 촬영·작성 안내 |
|---|---|---|---|

## 3. 기능별 자료

| 기능 | 필요한 자료 |
|---|---|
| 공지 | 오픈 공지 인사말 (10 문서 초안 확인) |
| 일정 | 2026-2027 학사 일정 확인 (data 폴더에 정리 완료. 3학기 종료일 확인 필요) |
| 갤러리 | 첫 게시물로 올릴 사진 묶음 (행사별 폴더) |
| Q&A | 자주 묻는 질문 5~10개와 답변 (없으면 초안 작성해 드림) |
| 회원가입 | 가입 대상(재학생 학부모만인지), 승인 방식(자동 / 관리자 승인) |
| 신청서 | 신청 접수 후 자동 답장 문구, 연락까지 걸리는 기간 (예: 2 영업일 안에) |
| 카드 결제 | 결제 항목과 금액, 환불 규정 |
| 개인정보 | 개인정보 처리 담당자 이름·연락처 (08 문서 참고) |

## 4. 참고 자료 ★

- 참고하고 싶은 홈페이지 1~3개와 마음에 드는 점
- 지금 홈페이지에서 유지할 것 / 바꾸고 싶은 것
- 원하는 분위기 (예: 따뜻한 / 단정한 / 활기찬)
